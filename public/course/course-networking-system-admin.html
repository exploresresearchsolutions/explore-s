About the Program

What is the Networking & System Admin Program?

This program trains you to design, configure and troubleshoot the networks and servers that connect every modern organisation. You'll build a strong foundation in routing, switching and system administration.

By the end of the course, you'll be able to configure enterprise networking devices, manage Windows Server infrastructure, and monitor IT systems — the exact skill set employers look for in network and system admin freshers.
